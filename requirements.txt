# 扫描件 OCR + 面板标签校验。装 RapidOCR：https://github.com/RapidAI/RapidOCR
# 两个后端跑的是同一套 PP-OCR 权重
# （RapidOCR 是把百度的模型转成 ONNX，版权仍归百度），所以这不是精度取舍，
# 而是同一个模型的两种跑法。ocr_engine.py 优先 RapidOCR，没有才回退 PaddleOCR。
#
# 装它。约 40MB（onnxruntime 常常已被别的包带进来），
# 实测同权重快 7.9 倍、用它更轻的默认档快 18.7 倍。
# --no-deps 是必须的：它声明依赖 opencv_python，而多数环境装的是
# opencv-contrib-python，两者争同一个 cv2 目录。contrib 版供的 cv2 完全够用
# （实测换过去 6 页输出逐字一致）。
#   pip install --no-deps rapidocr
#   pip install onnxruntime shapely pyclipper omegaconf colorlog
# 实测版本 rapidocr 3.9.2 + onnxruntime 1.26.0（Python 3.13）。
# rapidocr>=3.9
